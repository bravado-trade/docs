The fastest way to see what Bravado does is to watch live prediction-market data flow. In this guide you connect to Bravado's WebSocket, receive realtime trades across the most active markets, subscribe to an order book, and then enrich what you see through REST. No trade required, and the market-data streams are **public**, so you can start with zero setup.

<Note>
  **Came here to place a trade?** Jump straight to the [Execute a Trade](/quickstart-trade) quickstart. You can always come back for the data layer.
</Note>

<Steps>
  <Step title="Connect to the trade feed">
    Bravado's live trade feed is at `wss://partner-api.bravadotrade.com/trade-feed/ws`. It needs no API key. On connect you receive a `snapshot` of recent trades, then a `trade` frame for every new fill.

    <CodeGroup>

    ```javascript JavaScript
    const ws = new WebSocket("wss://partner-api.bravadotrade.com/trade-feed/ws");

    ws.onopen = () => console.log("connected");

    ws.onmessage = (event) => {
      const frame = JSON.parse(event.data);
      if (frame.type === "snapshot") {
        console.log(`snapshot: ${frame.trades.length} recent trades`);
      } else if (frame.type === "trade") {
        const t = frame.trade;
        console.log(`${t.side} ${t.size} ${t.outcome} @ ${t.price} — ${t.traderName}`);
      }
    };
    ```

    ```python Python
    import asyncio, json, websockets  # pip install websockets

    async def main():
        url = "wss://partner-api.bravadotrade.com/trade-feed/ws"
        async with websockets.connect(url, ping_interval=None) as ws:
            async for message in ws:
                frame = json.loads(message)
                if frame["type"] == "snapshot":
                    print(f"snapshot: {len(frame['trades'])} recent trades")
                elif frame["type"] == "trade":
                    t = frame["trade"]
                    print(f"{t['side']} {t['size']} {t['outcome']} @ {t['price']} — {t['traderName']}")

    asyncio.run(main())
    ```

    </CodeGroup>

    You should immediately see fills scrolling past. Each `trade` frame is already enriched server-side with the trader's name and wallet, no extra lookups needed. See the [Live Trades reference](/api/market-data/trade-feed) for the full frame shape.
  </Step>

  <Step title="Grab an asset ID to watch">
    Every trade frame carries an `assetId`, the outcome token ID that just traded. That is exactly what you need to subscribe to an order book. Pull one off the feed:

    ```javascript JavaScript
    let assetId;
    ws.onmessage = (event) => {
      const frame = JSON.parse(event.data);
      const trade = frame.type === "trade" ? frame.trade : frame.trades?.[0];
      if (trade && !assetId) {
        assetId = trade.assetId;
        console.log("watching asset", assetId);
      }
    };
    ```

    The same `assetId` links Market Data to the rest of Bravado: pass it to the order-book feed below, or to the [Trade API](/products/trade-api) as a `symbol` when you want to place an order.
  </Step>

  <Step title="Subscribe to an order book">
    Connect to `wss://partner-api.bravadotrade.com/orderbook-feed/ws?assetId=<TOKEN_ID>`. You receive a `book` snapshot (as a JSON array), then incremental `price_change` and `last_trade_price` updates.

    <CodeGroup>

    ```javascript JavaScript
    const assetId = "30216744678008528463608643201923934636445750175747926295346908540738127891986";
    const book = new WebSocket(
      `wss://partner-api.bravadotrade.com/orderbook-feed/ws?assetId=${assetId}`
    );

    book.onmessage = (event) => {
      const msg = JSON.parse(event.data);
      const events = Array.isArray(msg) ? msg : [msg];
      for (const e of events) {
        if (e.event_type === "book") {
          console.log(`book: best bid ${e.bids.at(-1)?.price}, best ask ${e.asks[0]?.price}`);
        } else if (e.event_type === "price_change") {
          console.log("price_change", e.price_changes.length, "levels");
        } else if (e.event_type === "last_trade_price") {
          console.log("last trade", e.price);
        }
      }
    };
    ```

    ```python Python
    import asyncio, json, websockets

    ASSET = "30216744678008528463608643201923934636445750175747926295346908540738127891986"

    async def main():
        url = f"wss://partner-api.bravadotrade.com/orderbook-feed/ws?assetId={ASSET}"
        async with websockets.connect(url, ping_interval=None) as ws:
            async for message in ws:
                msg = json.loads(message)
                events = msg if isinstance(msg, list) else [msg]
                for e in events:
                    if e.get("event_type") == "book":
                        print("book:", len(e["bids"]), "bids", len(e["asks"]), "asks")
                    elif e.get("event_type") == "price_change":
                        print("price_change:", len(e["price_changes"]), "levels")

    asyncio.run(main())
    ```

    </CodeGroup>

    To watch many markets at once, subscribe with `?assetIds=id1,id2,id3` and add or drop assets live with `{"type":"sub","assetIds":[...]}` frames. See the [Order Books reference](/api/market-data/order-book).
  </Step>

  <Step title="Enrich through REST">
    Realtime frames tell you what is happening; the REST APIs tell you more about the who and the market. Two common follow-ups:

    Look up a wallet you saw trading, its PnL, positions, and history come from the [Trader Data API](/products/data-api). The tax-report surface is public, so you can try it with no key:

    ```bash
    curl "https://partner-api.bravadotrade.com/trader-analytics/traders/0x9783F45CE35F794BE38cA47dD0816A5C241383B9/tax-report"
    ```

    Check feed health from a dashboard or monitor:

    ```bash
    curl https://partner-api.bravadotrade.com/trade-feed/status
    ```

    Most Trader Data and all Trade API endpoints require an API key. Create one in the [Bravado Portal](https://portal.bravadotrade.com/) and see [Authentication](/authentication).
  </Step>
</Steps>
