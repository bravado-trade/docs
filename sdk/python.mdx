The official Python SDK is still in development. Use the [signed Python client example](/authentication-examples) with `requests`, or the dependency-free [Trade quickstart](/quickstart-trade).

Create a public key and secret in [Console](https://console.bravadotrade.com/keys). Store both server-side as `BRAVADO_API_KEY` and `BRAVADO_API_SECRET`. A generated OpenAPI client also needs a per-request HMAC signing hook; supplying the public key alone is not sufficient.
