## Create an account or log in

[**Create account**](https://console.bravadotrade.com/signup) to get started, or [**log in**](https://console.bravadotrade.com/login) if you already have one. The Bravado Console is your developer dashboard for API access, usage, billing and your team.

## Start with your organisation

The [Console](https://console.bravadotrade.com) creates an organisation at first sign-in when you have no membership, after accepting eligible invitations. You become its owner. Billing changes apply to this existing organisation. The Free plan includes the Data API and the MCP Server; Market Data needs a paid plan, and Trade access requires the corresponding entitlements.

An endpoint groups a product's credentials, usage and settings. There is one endpoint per product per organisation. Creating an endpoint does not by itself grant scopes, venues or plan features. Use [Endpoints](https://console.bravadotrade.com/endpoints) to set up your products.

## The four products

| Product | Console endpoint | Credential | Build with it | Documentation |
| --- | --- | --- | --- | --- |
| **Data API** | Data API | HMAC key, `analytics.read` | Trader PnL, positions, leaderboards, tax statements; market-wide Combos data | [Data API](/products/data-api) |
| **Market Data** | Market Data | HMAC key, `stream.read` (paid plan) | Live order books, trades and combo fills; UMA resolution; mempool fills (partner tier) | [Market Data](/products/market-data) |
| **Trade API** | Trade API | HMAC key, `trade.*` scopes | Orders, strategies, positions, withdrawals, sub-accounts | [Trade API](/products/trade-api) |
| **MCP Server** | MCP Server | OAuth connection | Analytics and SQL tools for Claude and other agents | [MCP Server](/products/mcp-server) |

## Included in a product

These are not separate endpoints or keys. Each one uses the credential of the product it belongs to.

| Capability | Part of | Scope or access | Documentation |
| --- | --- | --- | --- |
| Trader analytics (`/trader-analytics/*`) | Data API | `analytics.read` | [Trader analytics reference](/api/analytics/overview) |
| Combos Data (`/v2/data/combos/*`) | Data API | `analytics.read` | [Combos Data](/api/combos-data/overview) |
| Live trades, order books, combo trades | Market Data | `stream.read` | [Feeds](/products/market-data#feeds) |
| UMA resolution (REST and stream) | Market Data | `stream.read`, paid plan | [UMA resolution](/products/uma-api) |
| Mempool Fills | Market Data | Partner feed token | [Mempool Fills](/api/market-data/mempool-feed) |
| Combos (RFQ, accept, redeem) | Trade API | `trade.combos` | [Combos](/api/combos/overview) |
| Copytrade | Trade API | `trade.copytrade` | [Copytrade](/products/copytrade-api) |
| Sub-accounts | Trade API | `trade.users` | [Account](/api/trade/account) |
| Withdrawals | Trade API | `trade.withdraw` | [Withdraw](/api/trade/withdraw) |

## Match the venue to the workflow

Both Polymarket and Predict.fun support LIMIT, MARKET, PEGGED, TWAP and ICEBERG on the v2 Trade surface. Conditional orders, brackets, Combos and Copytrade are Polymarket-only. TRAILING_BUY additionally requires its deployment feature flag. Read the [Polymarket](/markets/polymarket/trade-api) and [Predict.fun](/markets/predict-fun/trade-api) guides for detailed constraints, and [supported venues](/markets/overview) for coverage by product.
