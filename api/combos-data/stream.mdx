This feed is part of [Market Data](/products/market-data). Connect to `wss://partner-api.bravadotrade.com/stream/polymarket/partner/combos` using a **Market Data** credential (`stream.read`) and [HMAC authentication](/authentication). It is metered and billed exactly like [`/stream/polymarket/partner/trades`](/api/market-data/trade-feed); a Data API key is refused on this route.

No subscription message is needed: the channel is the path. On connect the server sends a snapshot of the most recent settlements it has seen, then one frame per new settlement.

```json Snapshot
{ "type": "snapshot", "trades": [ { "type": "combo_trade", "...": "..." } ] }
```


<Info>
  Taker side only: one frame per settlement, never the maker fills it matched. Decimals use the same fixed-scale strings as the REST routes. Frames arrive after on-chain finality (about 1 to 2 minutes behind the block), so this feed is for monitoring and analytics, not for front-running a settlement. History is served by [`GET /v2/data/combos/trades`](/api/combos-data/trades); the socket never replays it.
</Info>

`GET /stream/capabilities` advertises the route as `combos_path` for `polymarket` when it is available.

## Connect

Create a Market Data credential in [Console](https://console.bravadotrade.com/endpoints/ws_stream?section=keys) and sign the connection the same way as the [Live Trades](/api/market-data/trade-feed#connect-with-usage-tracking) feed, with `path` set to `/stream/polymarket/partner/combos`.
