---
title: "GET /v2/data/combos/{combo_id}: Combo Detail"
sidebarTitle: "/combos/{combo_id}"
api: "GET /v2/data/combos/{combo_id}"
description: "One combo in full: its legs, its distinct underlying markets and its 50 most recent settlements."
---

<Note>Sign each request with a fresh HMAC signature. The cURL and HTTP header values below are placeholders, not reusable credentials. For runnable signing code, use [request signing examples](/authentication-examples).</Note>

```text
GET https://partner-api.bravadotrade.com/v2/data/combos/{combo_id}
```

### Path Parameters

<ParamField path="combo_id" type="string" required>
  The combo's condition id: bytes31 (`0x` plus 62 hex characters) or the 32-byte wire form padded with `00`.
</ParamField>

### Response

<ResponseField name="combo" type="object">
  The same object as one row of [`GET /v2/data/combos`](/api/combos-data/list#response).
</ResponseField>

<ResponseField name="markets" type="array">
  The combo's distinct underlying markets, as leg objects. A market that appears in several legs is listed once.
</ResponseField>

<ResponseField name="recent_trades" type="array">
  The 50 most recent settlements (taker fills), as [ComboTrade](/api/combos-data/trades#response) objects. For the full history page through `GET /v2/data/combos/trades?combo_id=`.
</ResponseField>

### Errors

| Status | When |
| --- | --- |
| `400 Bad Request` | `INVALID_COMBO_ID`: not a bytes31 or padded 32-byte hex id |
| `401 Unauthorized` | Missing or invalid HMAC credentials, or not a Data API key |
| `404 Not Found` | `COMBO_NOT_FOUND`: well-formed id that has not been indexed |
| `429 Too Many Requests` | Rate limit exceeded, see `Retry-After` header |
