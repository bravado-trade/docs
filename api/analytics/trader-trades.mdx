Returns a paginated log of all trade events for the wallet in reverse chronological order.

```text
GET https://partner-api.bravadotrade.com/trader-analytics/traders/{address}/trades
```

### Path Parameters

### Query Parameters

  

<ParamField query="type" type="string">
  Filter by event type: `TRADE`, `REDEEM`, `REWARD`, `MAKER_REBATE`, `REFERRAL_REWARD`, `SPLIT`, `MERGE`, `CONVERSION`, `DEPOSIT`, `WITHDRAW`.
</ParamField>

### Response

<ResponseField name="trades" type="array">
  <Expandable title="Trade event fields">
    <ResponseField name="block_timestamp" type="integer">
      Unix timestamp of the block.
    </ResponseField>

    <ResponseField name="ts" type="string">
      ISO 8601 UTC string.
    </ResponseField>

    <ResponseField name="tx_hash" type="string">
      Polygon transaction hash.
    </ResponseField>

    <ResponseField name="market_id" type="string">
      Polymarket condition ID.
    </ResponseField>

    <ResponseField name="question" type="string">
      Market question.
    </ResponseField>

    <ResponseField name="category" type="string">
      Market category.
    </ResponseField>

    <ResponseField name="outcome" type="string">
      Outcome label.
    </ResponseField>

    <ResponseField name="token_id" type="string">
      ERC-1155 token ID.
    </ResponseField>

    <ResponseField name="side" type="string">
      `"BUY"` or `"SELL"`.
    </ResponseField>

    <ResponseField name="shares" type="string">
      Number of shares.
    </ResponseField>

    <ResponseField name="usdc_amount" type="string">
      USDC value exchanged.
    </ResponseField>

    <ResponseField name="price_cents" type="string">
      Implied price in cents (0–100).
    </ResponseField>

    <ResponseField name="event_type" type="string">
      Event classification.
    </ResponseField>

    <ResponseField name="shares_source" type="string" default="omitted">
      On a `REDEEM` row only: `"payload"` when `shares` is measured exactly
      from the on-chain redemption event. **Omitted (not `""`) when the
      redeemed share count could not be determined** — `shares` is then the
      empty string `""`, deliberately never a fake `"0"`.
    </ResponseField>

    <ResponseField name="price_cents_source" type="string" default="omitted">
      On a `REDEEM` row only: `"payload"` when `price_cents` is an exact
      payout-per-share (computed from the redemption's real payout and share
      count) — `0` for a losing outcome, `100` for a full winning payout,
      fractional for a partial/split resolution. **Omitted when the redeemed
      share count is unknown** (mirrors `shares_source`): `price_cents` then
      stays `0` as a pending placeholder, not a claim the payout was zero —
      check this field before trusting `price_cents` on a REDEEM row.
    </ResponseField>

    <ResponseField name="log_index" type="integer" default="omitted">
      On `DEPOSIT`/`WITHDRAW` rows sourced from our own on-chain data: the
      on-chain log index of the transfer, alongside `tx_hash` — together they
      identify the exact event even when several logs share one transaction.
      Omitted (never a fabricated `0`) when the source has no log index (a
      row that fell back to a third-party API), or when `tx_hash` itself is
      unavailable.
    </ResponseField>
  </Expandable>
</ResponseField>

**Deposits and withdrawals.** `type=DEPOSIT`/`WITHDRAW` rows are sourced from
our own on-chain ClickHouse tables first (real `tx_hash` + `log_index` by
construction), falling back to a third-party API only for a transfer our own
detection does not cover. A `WITHDRAW` row here is specifically a **pUSD
burn** — Polymarket's definition of a withdrawal. A withdrawal made through
Bravado's own infrastructure is a plain ERC-20 transfer, not a burn, and is
not yet represented on this surface.

### Pagination Example

<CodeGroup>

```bash First page
curl -G https://partner-api.bravadotrade.com/trader-analytics/traders/0xabc.../trades \
  -H "Authorization: Bearer <token>" \
  -d limit=100
```

```bash Next page
curl -G https://partner-api.bravadotrade.com/trader-analytics/traders/0xabc.../trades \
  -H "Authorization: Bearer <token>" \
  -d limit=100 \
  -d cursor_ts=1736800000 \
  -d cursor_log_idx=42
```

</CodeGroup>
