---
title: "GET /healthz: Data API Liveness Probe"
sidebarTitle: "/healthz"
api: "GET /trader-analytics/healthz"
description: "Unauthenticated liveness probe for the Bravado Data API."
---

Returns `200` when the Data API is healthy. No authentication required.

```text
GET https://partner-api.bravadotrade.com/trader-analytics/healthz
```

### Response

<ResponseField name="ok" type="boolean">
  `true` when the service is healthy.
</ResponseField>

<ResponseField name="ts" type="string">
  RFC 3339 UTC timestamp.
</ResponseField>

### Example

<CodeGroup>

```bash cURL
curl https://partner-api.bravadotrade.com/trader-analytics/healthz
```

```json Response
{
  "ok": true,
  "ts": "2025-01-15T12:00:00Z"
}
```

</CodeGroup>
