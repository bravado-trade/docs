Returns traders on Polymarket ranked by realized PnL for the requested window. All PnL values are computed under [PMWAS](/products/data-api). For volume-ranked results, use [`GET /leaderboard/volume`](/api/analytics/leaderboard-volume).

```text
GET https://partner-api.bravadotrade.com/trader-analytics/leaderboard
```

### Query Parameters

<ParamField query="window" default="30d" type="string">
  Rolling time window over which to compute PnL. One of `24h`, `7d`, `30d`, `all`.
</ParamField>

<ParamField query="limit" default="100" type="integer">
  Number of traders to return. Maximum 500.
</ParamField>

<ParamField query="offset" default="0" type="integer">
  Offset for pagination. See [Pagination](/reference/pagination).
</ParamField>

<ParamField query="category" type="string">
  Filter: keep only wallets whose **dominant** category (by volume, for this board's window) equals this value. One of `Politics`, `Crypto`, `Sports`, `Science`, `Tech`, `Entertainment`, `Earnings`, `Finance`, `Geopolitics`, `World`, `Elections`, `Weather`, `Other`. Not "rank within category X" — see the same param on [`GET /leaderboard/volume`](/api/analytics/leaderboard-volume) for the full semantics (window/venue/backfill restrictions are identical on both boards).
</ParamField>

### Response

<ResponseField name="results" type="array">
  <Expandable title="LeaderboardRow fields">
    <ResponseField name="rank" type="integer">
      1-based rank in the window.
    </ResponseField>

    <ResponseField name="trader" type="string">
      Polygon wallet address.
    </ResponseField>

    <ResponseField name="username" type="string | null">
      Polymarket display name if the wallet has one.
    </ResponseField>

    <ResponseField name="avatar" type="string | null">
      Avatar image URL.
    </ResponseField>

    <ResponseField name="bravado_user_id" type="string | null">
      Internal Bravado user identifier if this wallet is provisioned through Bravado.
    </ResponseField>

    <ResponseField name="pnl_usdc" type="string">
      Realized PnL in USDC over the window, net of fees. String for precision.
    </ResponseField>

    <ResponseField name="volume_usdc" type="string">
      Total USDC notional traded in the window.
    </ResponseField>

    <ResponseField name="trades" type="integer">
      Trade events in the window.
    </ResponseField>

    <ResponseField name="win_rate" type="string">
      Fraction of closed positions with positive realized PnL. String between "0" and "1".
    </ResponseField>

    <ResponseField name="category" type="string | null">
      The wallet's dominant category for this board's window (by volume). `null` when unknown — see `category_basis`; see [`GET /leaderboard/volume`](/api/analytics/leaderboard-volume) for full field semantics (identical on both boards).
    </ResponseField>

    <ResponseField name="category_share" type="string | null">
      `category`'s share of the wallet's own `volume_usdc` in the window. Present only alongside `category`.
    </ResponseField>

    <ResponseField name="category_basis" type="string">
      Why `category` is present or absent: `all_time` / `window_daily`, `no_classifiable_volume`, `backfill_incomplete`, `unavailable_sub_day`, or `unsupported_venue`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="window" type="string">
  Echo of the window parameter used for the response.
</ResponseField>

<ResponseField name="total" type="integer">
  Total number of traders matching the window.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  True if additional pages exist.
</ResponseField>

<ResponseField name="totals" type="object | null">
  Board-wide aggregate over the **same candidate set** as `total` (window, `min_trades`, `is_mm_bot`/`exclude_bots`, and — for the PnL sums — `basis`) — for a stat-strip header, not for paging. `null` only if it could not be computed.

  <Expandable title="PnLLeaderboardTotals fields">
    <ResponseField name="traders" type="integer">
      Always equal to the response's `total`.
    </ResponseField>

    <ResponseField name="volume_usdc" type="string">
      Sum of `volume_usdc` over the candidate set.
    </ResponseField>

    <ResponseField name="trades" type="integer">
      Sum of `trades` over the candidate set.
    </ResponseField>

    <ResponseField name="realized_pnl" type="string">
      Sum of realized PnL over the candidate set (respects `?basis=`).
    </ResponseField>

    <ResponseField name="unrealized_pnl" type="string">
      Sum of current open mark-to-market over the candidate set.
    </ResponseField>

    <ResponseField name="total_pnl" type="string">
      Sum of `realized_pnl + unrealized_pnl` over the candidate set.
    </ResponseField>

    <ResponseField name="profitable_traders" type="integer">
      Count of wallets in the candidate set with `total_pnl > 0`.
    </ResponseField>

    <ResponseField name="unprofitable_traders" type="integer">
      Count of wallets in the candidate set with `total_pnl < 0`.
    </ResponseField>
  </Expandable>
</ResponseField>

### Errors

| Status | When |
| --- | --- |
| `400 Bad Request` | Invalid `window`, `limit`, `offset`, or `category` value, or `category` requested for a window/venue it isn't available on yet |
| `401 Unauthorized` | Missing or invalid Bearer token |
| `429 Too Many Requests` | Rate limit exceeded, see `Retry-After` header |

See the [Error reference](/reference/errors).

### Example

<CodeGroup>

```bash cURL
curl -G https://partner-api.bravadotrade.com/trader-analytics/leaderboard \
  -H "Authorization: Bearer <token>" \
  -d window=30d \
  -d limit=20
```
