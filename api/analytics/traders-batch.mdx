<Note>Sign each request with a fresh HMAC signature. The cURL and HTTP header values below are placeholders, not reusable credentials. For runnable signing code, use [request signing examples](/authentication-examples). Python examples use the signed session from that page; Node.js examples use its `bravadoFetch` helper.</Note>

Returns headline performance for up to 50 wallets in one call, so you can screen a holder list before you open individual wallets with [`/traders/{address}`](/api/analytics/trader). At least 20 addresses per call are always accepted.

```text
GET https://partner-api.bravadotrade.com/trader-analytics/traders/batch
```

### Query Parameters

<ParamField query="addresses" type="string" required>
  Comma-separated wallet addresses, at most 50. The `0x` prefix is optional. Duplicates are collapsed and request order is kept.
</ParamField>

### Response

<ResponseField name="requested" type="integer" required>
  Number of distinct addresses requested.
</ResponseField>

<ResponseField name="found" type="integer" required>
  Number of addresses with indexed activity.
</ResponseField>

<ResponseField name="traders" type="array" required>
  One row per distinct address, in request order. Row fields are listed under [Trader fields](#trader-fields).
</ResponseField>

<ResponseField name="not_found" type="array" required>
  Addresses with no indexed activity and a provably empty ledger. An empty array when every address was found.
</ResponseField>

<ResponseField name="unresolved" type="array" required>
  Addresses that are neither found nor provably empty: the service had no score row for them and could not read their ledger within budget. Treat them as unknown, not as "no data". An empty array when there are none.
</ResponseField>

<ResponseField name="note" type="string" required>
  A fixed caveat: this is a screening view, realized PnL is all-time and settled, and it excludes open positions.
</ResponseField>

#### Trader fields

A row for a wallet with `found: false` carries only `trader`, `found` and `is_mm_bot`.

| Field | Type | Meaning |
| --- | --- | --- |
| `trader` | string | Wallet address. |
| `found` | boolean | `false` when the wallet has no indexed activity. Such wallets are returned, not dropped, and listed under `not_found`. |
| `realized_pnl` | string | All-time settled realized PnL, from the per-fill ledger (the same figure as [`/traders/{address}`](/api/analytics/trader)). **Omitted when `realized_pnl_status` is `unknown`. It is never `0` in that case.** |
| `realized_pnl_status` | string | `known` or `unknown`. `unknown` means the exact realized PnL could not be read within the service's read budget for this wallet, usually because it has a very large history. |
| `realized_pnl_unknown_reason` | string | Present only when `realized_pnl_status` is `unknown`. Currently `read_cap_exceeded`. Request the wallet alone from [`/traders/{address}/pnl`](/api/analytics/trader-pnl) to get its figure. |
| `volume_usdc` | string | All-time volume, a decimal string. |
| `trades` | integer | Trade count. |
| `markets_traded` | integer | Markets traded. |
| `markets_won` | integer | Number of markets won. |
| `markets_lost` | integer | Number of markets lost. |
| `decided_markets` | integer | `markets_won + markets_lost`, the denominator behind `win_rate`. |
| `win_rate` | string | Won divided by decided markets, a decimal string. |
| `is_mm_bot` | boolean | Market-maker flag. |
| `windows` | object | The profile windows (`1d`, `7d`, `30d` and all-time), as on [`/traders/{address}`](/api/analytics/trader). |
| `style` | object | Trading-style flags, and `primary_style`. |
| `style_source` | string | Where `style` was read from. |
| `computed_at` | integer | Unix timestamp, in seconds, of the score computation behind the row. |

**Unknown is not zero.** A wallet with `realized_pnl_status: "unknown"` has no `realized_pnl` field. Do not sum it as `0`.

**Venues.** The same contract is served for predict.fun at `/trader-analytics/predict/traders/batch`.

## Errors

| Status | Code | Meaning |
| --- | --- | --- |
| `400` | none | `addresses` is missing, empty, has more than 50 entries, or contains an invalid address. The body is `{"error": "..."}` without a `code`. |

### Example

```bash cURL
curl -G https://partner-api.bravadotrade.com/trader-analytics/traders/batch \
  -H "X-BRAVADO-API-KEY: $BRAVADO_API_KEY" \
  -H "X-BRAVADO-TIMESTAMP: <unix-ms>" \
  -H "X-BRAVADO-SIGNATURE: <signature-for-this-request>" \
  -d addresses=0xabc...,0xdef...
```
