<Note>Sign each request with a fresh HMAC signature. The cURL and HTTP header values below are placeholders, not reusable credentials. For runnable signing code, use [request signing examples](/authentication-examples). Python examples use the signed session from that page; Node.js examples use its `bravadoFetch` helper.</Note>


Returns the same trade log as [`/traders/{address}/trades`](/api/analytics/trader-trades), but the wallet address is passed as a query parameter instead of a path segment. Response shape is identical.

```text
GET https://partner-api.bravadotrade.com/trader-analytics/trades
```

### Query Parameters

<ParamField query="address" type="string" required>
  Wallet address (`wallet` and `user` are accepted aliases).
</ParamField>

<ParamField query="type" type="string">
  Event type, as on [`/traders/{address}/trades`](/api/analytics/trader-trades): `TRADE`, `SETTLE`, `REDEEM`, and the others listed there.
</ParamField>

<ParamField query="cursor_ts" type="integer">
  Previous page's `next_cursor`.
</ParamField>

<ParamField query="cursor_block" type="integer">
  Previous page's `next_cursor_block`. Required with any cursor on the default, `TRADE` and `SETTLE` feeds; `0` means no trade row served yet; the response then omits `next_cursor_log_idx`, `next_cursor_tx` and `next_cursor_token`.
</ParamField>

<ParamField query="cursor_log_idx" type="integer">
  Previous page's `next_cursor_log_idx`.
</ParamField>

<ParamField query="cursor_tx" type="string">
  Previous page's `next_cursor_tx`.
</ParamField>

<ParamField query="cursor_token" type="string">
  Previous page's `next_cursor_token`.
</ParamField>

### Pagination and errors

Identical to [`/traders/{address}/trades`](/api/analytics/trader-trades#pagination-keyset-cursor): pass the five `next_cursor*` fields back as `cursor_ts`, `cursor_block`, `cursor_log_idx`, `cursor_tx`, `cursor_token`. A cursor missing its block, or any part of the key, is `400 invalid_cursor`. Both venues (`/trader-analytics/predict/trades` for predict.fun) follow the same rules.

### Response

Same shape as [/traders/](/api/analytics/trader-trades#response){address}[/trades](/api/analytics/trader-trades#response).

### Example

```bash cURL
curl -G https://partner-api.bravadotrade.com/trader-analytics/trades \
  -H "X-BRAVADO-API-KEY: $BRAVADO_API_KEY" \
  -H "X-BRAVADO-TIMESTAMP: <unix-ms>" \
  -H "X-BRAVADO-SIGNATURE: <signature-for-this-request>" \
  -d address=0xabc... \
  -d limit=100
```
