<Note>Sign each request with a fresh HMAC signature. The cURL and HTTP header values below are placeholders, not reusable credentials. For runnable signing code, use [request signing examples](/authentication-examples). Python examples use the signed session from that page; Node.js examples use its `bravadoFetch` helper.</Note>


Returns only the wallet's currently open positions. Response shape matches [/positions](/api/analytics/trader-positions).

```text
GET https://partner-api.bravadotrade.com/trader-analytics/traders/{address}/positions/active
```

### Path Parameters

### Response

Array of position objects. See [/positions field reference](/api/analytics/trader-positions#response-position-fields) for the full schema.

### Example

```bash cURL
curl https://partner-api.bravadotrade.com/trader-analytics/traders/0xabc.../positions/active \
  -H "X-BRAVADO-API-KEY: $BRAVADO_API_KEY" \
  -H "X-BRAVADO-TIMESTAMP: <unix-ms>" \
  -H "X-BRAVADO-SIGNATURE: <signature-for-this-request>"
```
