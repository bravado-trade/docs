The `/v2/polymarket` surface serves Polymarket wallet and market analytics under a single Data API credential (`analytics.read`). Every route is **fixed to the Polymarket venue** — there is no `venue` parameter to pass.

### Response conventions

For leaderboard and wallet profiles (single and batch):

- **Metrics are JSON numbers or `null`**, including USD amounts, prices, ratios and counts. The source constructs exact decimal number tokens; use a decimal-aware parser when exact decimal precision matters. ROI and win rate are `0`–`1` ratios.
- **Timestamps are unix seconds** (`computed_at`, `first_trade_at`, `last_trade_at`, …).
- **Unknown is `null`, never a fake `0`.** A metric the source cannot compute is `null`. In particular `fees_paid` is `null` on the day windows and `fees_refunded` is `null` on every window — this surface has no per-window fee split — so a `null` fee means *unknown*, not *zero*.
- **Cursor pagination.** List endpoints return `pagination.pagination_key`; pass it back as the `pagination_key` query parameter to get the next page. `pagination.has_more` tells you when to stop.

PnL follows the source’s fee basis. Once the engine and rebuilt rollups certify
fee-net data, the compat routes return those net values unchanged; `fees_paid`
is informational and must not be subtracted again. During pre-cutover coverage,
the source retains the corresponding gross basis. There is no `basis` query
parameter on these compat routes. `total_pnl` includes current unrealized PnL,
so it is nullable when that value is unavailable.

Positions and other endpoints follow their own documented response schema,
including their units and timestamp precision.

### Endpoints

- [`GET /v2/polymarket/leaderboard`](/api/polymarket/leaderboard) — wallets ranked for a window.
- [`GET /v2/polymarket/wallet/{wallet}`](/api/polymarket/wallet) — one wallet's four-window profile.
- [`GET /v2/polymarket/wallets/profiles`](/api/polymarket/wallets-profiles) — a batch of wallet profiles.
- [`GET /v2/polymarket/markets/smart-activity`](/api/polymarket/smart-activity) — per-market smart-cohort aggregates.
- [`GET /v2/polymarket/positions`](/api/analytics/positions) — positions across every indexed wallet (documented alongside the canonical positions endpoint).
