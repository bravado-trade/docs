Two reads of the user's venue account. Scope `perps.read`.

The perps balance is separate from the deposit wallet: pUSD deposited to Perps cannot back prediction-market orders until you [withdraw it](/api/trade/perps/withdraw).

## Account

```text
GET https://partner-api.bravadotrade.com/v2/trade/perps/account
```

### Response

The margin summary, the liquidation state, and:

<ResponseField name="withdrawable" type="string">
  pUSD that can be withdrawn now. `"max"` on [`POST /v2/trade/perps/withdrawals`](/api/trade/perps/withdraw) withdraws this amount; an amount above it answers `422 INSUFFICIENT_BALANCE`.
</ResponseField>

### Example

<CodeGroup>

```bash cURL
curl https://partner-api.bravadotrade.com/v2/trade/perps/account \
  -H "X-BRAVADO-API-KEY: $BRAVADO_API_KEY" \
  -H "X-BRAVADO-TIMESTAMP: <unix-ms>" \
  -H "X-BRAVADO-SIGNATURE: <signature-for-this-request>"
```

</CodeGroup>

## Balances

```text
GET https://partner-api.bravadotrade.com/v2/trade/perps/balances
```

### Response

The user's balances at the venue.
