Two reads: every deposit of the user, or one deposit by the `deposit_id` that [`POST /v2/trade/perps/deposits`](/api/trade/perps/deposit) answered. Scope `perps.read`.

Deposit states update about once a minute, so polling faster returns the same object.

## List deposits

```text
GET https://partner-api.bravadotrade.com/v2/trade/perps/deposits
```

### Query Parameters

<ParamField query="cursor" type="string">
  Opaque. Pass back the previous page's `next_cursor`.
</ParamField>

### Response

The user's deposits. When there are more, pass the page's `next_cursor` back as `cursor`.

After a `504` on a deposit, list deposits before acting again: the request may have acted.

## Get one deposit

```text
GET https://partner-api.bravadotrade.com/v2/trade/perps/deposits/{deposit_id}
```

### Path Parameters

<ParamField path="deposit_id" type="string" required>
  The `deposit_id` the `POST` answered, a UUID.
</ParamField>

### Response

The deposit, with its `state`. Poll until `state` is `credited`. States are `prepared`, `pending` (sent, not yet confirmed and credited), `confirmed` (on chain, not yet credited by the venue), `credited`, `failed`, `reverted` and `not_found`.

### Errors

| Status | When |
| --- | --- |
| `404 Not Found` | `NOT_FOUND`: unknown id, or one that belongs to another user |
