Bravado is the data infrastructure layer for prediction markets. Stream realtime market data, pull trader intelligence, track resolution, and execute, all through one API surface, so you integrate with Bravado once instead of maintaining a separate integration per venue. [Polymarket](/markets/polymarket/overview) is supported across every product; see [supported prediction markets](/markets/overview) for coverage by venue.

Create and manage your API keys in the [Bravado Portal](https://portal.bravadotrade.com/). The realtime market-data streams are public and need no key to start.

## Product categories

Bravado is organized around what kind of data you need, with execution available alongside it.

### Market Data

Realtime prediction-market data over WebSockets, and the primary infrastructure product. Stream live trades across the most active markets and live order books for any outcome token through Bravado infrastructure, already normalized and enriched, instead of connecting to each venue's socket yourself.

- Live trade feed, enriched server-side with trader name and wallet
- Live order books: snapshots, incremental updates, best bid/ask, last-trade price
- One multiplexed connection instead of one socket per market

See [Market Data](/products/market-data). Coverage today is Polymarket, with the interface designed to extend across venues.

### Trader Data API

Enriched participant intelligence derived from on-chain settlement: who is trading, how they perform, and what they hold. This is distinct from realtime market data, it is about **traders**, not the tape.

- Wallet positions, PnL, and cost basis
- Trade history and wallet activity
- Leaderboards, win rate, and trader analytics

See the [Trader Data API](/products/data-api).

### Execution

The [Trade API](/products/trade-api) covers the full order lifecycle across supported venues: standard order execution, eight order types including TWAP, ICEBERG, and bracket orders, and position management. Execution is a first-class capability you use **alongside** Bravado's data infrastructure, when you want data and trading behind one integration.

### Automation

The [Copytrade API](/products/copytrade-api) mirrors any wallet's fills with configurable sizing and risk controls, a specialized execution-automation product built on top of the Trade API.

### Resolution

The [UMA API](/products/uma-api) exposes how Polymarket markets settle through UMA's Optimistic Oracle: proposals, disputes, and final outcomes, so you can tell a concluded event from a redeemable position.

### Historical Data

We are building toward historical market-data infrastructure, historical trades and market-state history, so customers do not have to record every stream themselves. Historical **trader** data is available today through the [Trader Data API](/products/data-api), which reconstructs a wallet's full economic history from its first trade.

## API surfaces

| API | Base URL | What it does |
| --- | --- | --- |
| **Market Data** | `wss://partner-api.bravadotrade.com/trade-feed/ws`, `/orderbook-feed/ws` | Realtime trades and order books over WebSockets |
| **Trader Data API** | `https://partner-api.bravadotrade.com/trader-analytics` | Leaderboards, wallet PnL, trade logs, tax statements |
| **Trade API v2** | `https://partner-api.bravadotrade.com/v2/trade` | Order execution, positions, balances, user provisioning |
| **Copytrade API** | `https://partner-api.bravadotrade.com/v2/trade/copytrade` | Mirror fills from top traders with configurable sizing |

## Your first stream

The market-data feeds are public, no key required. Connect and watch live fills across the most active markets:

<CodeGroup>

```javascript JavaScript
const ws = new WebSocket("wss://partner-api.bravadotrade.com/trade-feed/ws");

ws.onmessage = (event) => {
  const frame = JSON.parse(event.data);
  if (frame.type === "trade") {
    const t = frame.trade;
    console.log(`${t.side} ${t.size} ${t.outcome} @ ${t.price} — ${t.traderName}`);
  }
};
```

```python Python
import asyncio, json, websockets  # pip install websockets

async def main():
    url = "wss://partner-api.bravadotrade.com/trade-feed/ws"
    async with websockets.connect(url, ping_interval=None) as ws:
        async for message in ws:
            frame = json.loads(message)
            if frame.get("type") == "trade":
                t = frame["trade"]
                print(f"{t['side']} {t['size']} {t['outcome']} @ {t['price']} — {t['traderName']}")

asyncio.run(main())
```

</CodeGroup>
