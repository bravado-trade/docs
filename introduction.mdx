Bravado is the data infrastructure layer for prediction markets. Stream realtime market data, pull trader intelligence, track resolution, and execute, all through one API surface, so you integrate with Bravado once instead of maintaining a separate integration per venue. [Polymarket](/markets/polymarket/overview) is supported across every product; see [supported prediction markets](/markets/overview) for coverage by venue.

The **Bravado Console** is your developer dashboard for API keys, usage, billing and your team.

## The four products

Every product is one endpoint in Console with its own credential. Capabilities such as Combos, Copytrade, UMA resolution or Combos Data are parts of a product, not products of their own.

### Data API

Enriched participant intelligence derived from on-chain settlement: who is trading, how they perform, and what they hold, plus market-wide data on Polymarket Combos. It is about **traders and settlements**, not the live tape.

- Wallet positions, PnL, and cost basis
- Trade history and wallet activity
- Leaderboards, win rate, and trader analytics
- Tax statements and reconciliation
- Every Polymarket combo settlement, with legs, stats and a combo leaderboard

See the [Data API](/products/data-api). Base paths `/trader-analytics` and `/v2/data`, one credential with `analytics.read`.

### Market Data

Realtime prediction-market data over WebSockets, and the primary infrastructure product. Stream live trades across every market and live order books for any outcome token through Bravado infrastructure, already normalized and enriched, instead of connecting to each venue's socket yourself.

- Live trade feed, enriched server-side with trader name and wallet
- Live order books: snapshots, incremental updates, best bid/ask, last-trade price
- Live combo settlements, one frame per fill
- UMA resolution: proposals, disputes and final outcomes, as queryable data and as a stream
- Mempool Fills, the low-latency partner tier
- One multiplexed connection instead of one socket per market

See [Market Data](/products/market-data). Order books cover Polymarket and Predict.fun; the other feeds cover Polymarket today. One credential with `stream.read` on a paid plan.

### Trade API

The [Trade API](/products/trade-api) covers the full order lifecycle across supported venues: eight order types including TWAP, ICEBERG, PEGGED and bracket orders, managed strategies, position management, withdrawals and sub-accounts. It includes [Combos](/api/combos/overview) (multi-leg RFQ, accept and redeem) and [Copytrade](/products/copytrade-api) (mirror any wallet's fills with configurable sizing) on the same credential, enabled per organisation. Execution is a first-class capability you use **alongside** Bravado's data infrastructure, when you want data and trading behind one integration.

### MCP Server

The [MCP Server](/products/mcp-server) gives Claude and other MCP clients OAuth access to Bravado's analytics and SQL tools. No API key lives in the client; connections are managed in Console.

### Historical Data

We are building toward historical market-data infrastructure, historical trades and market-state history, so customers do not have to record every stream themselves. Historical **trader** and **combo** data is available today through the [Data API](/products/data-api), which reconstructs a wallet's full economic history from its first trade and indexes every combo settlement from the chain.

## API surfaces

| Product | Base URL | Credential |
| --- | --- | --- |
| **Data API** | `https://partner-api.bravadotrade.com/trader-analytics`, `https://partner-api.bravadotrade.com/v2/data` | HMAC, `analytics.read` |
| **Market Data** | `wss://partner-api.bravadotrade.com/stream/{venue}/partner`, `/stream/polymarket/partner/trades`, `/stream/polymarket/partner/combos`, UMA at `/uma` | HMAC, `stream.read` |
| **Trade API** | `https://partner-api.bravadotrade.com/v2/trade` (Combos at `/v2/trade/combo`, Copytrade at `/v2/trade/copytrade`) | HMAC, `trade.*` |
| **MCP Server** | `https://mcp.bravadotrade.com` | OAuth |

## Your first request

[Create your account](https://console.bravadotrade.com/signup), set up the Data API endpoint and create its credential. The [quickstart](/quickstart) walks through one signed request and checking your organisation's usage. For a live stream, set up Market Data on a paid plan and follow [Live Trades](/api/market-data/trade-feed); each connection requires a fresh HMAC signature, an API key alone is not sufficient.
