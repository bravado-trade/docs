## Products

The four products map one-to-one to the endpoints you configure in [Console](https://console.bravadotrade.com/endpoints). Each endpoint issues its own credentials.

| Product | Base | Console endpoint | What it does |
| --- | --- | --- | --- |
| [**Data API**](/products/data-api) | `https://partner-api.bravadotrade.com/trader-analytics`, `/v2/data` | Data API | Trader PnL, positions, leaderboards, tax statements, and market-wide Combos data |
| [**Market Data**](/products/market-data) | `wss://partner-api.bravadotrade.com/stream/...` | Market Data | Live order books, trades and combo settlements, UMA resolution, mempool fills |
| [**Trade API**](/products/trade-api) | `https://partner-api.bravadotrade.com/v2/trade` | Trade API | Order execution, strategies, positions, withdrawals; includes Combos and Copytrade |
| [**MCP Server**](/products/mcp-server) | `https://mcp.bravadotrade.com` | MCP Server | OAuth access to Bravado analytics and SQL for Claude and other agents |

## Get started

<Steps>
  <Step title="Create an organisation">
    [Sign up](https://console.bravadotrade.com/signup) in Console. The Free plan includes the Data API and MCP Server; Market Data and Trade API need a paid plan or an entitlement.
  </Step>
  <Step title="Set up an endpoint">
    Open **Endpoints**, pick a product and create its credential. One endpoint per product per organisation; keys and usage live under it.
  </Step>
  <Step title="Make a signed call">
    Follow the [quickstart](/quickstart) for a signed Data API request, or the [Trade quickstart](/quickstart-trade) to place an order.
  </Step>
  <Step title="Watch usage">
    **Usage** in Console shows calls, delivered bytes and credits per product. See [API credits](/api-credits).
  </Step>
</Steps>
